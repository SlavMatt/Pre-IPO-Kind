This perpetual trades 24/7, and its price is based on various market price. Prices may fluctuate during the Pre-IPO phase — please be mindful of the risks. When the underlying asset officially launch on IPO market, the liquidity and price protection may adjust to regular {stock} market

描述文字
三个核心风险信息：24/7 交易、价格基于 OTC 估值、上市后规则切换。
这三点直接影响用户风险判断，必须在弹窗顶部前置展示。
IPO · 6 种触发条件（Type 1）
State 1 — ipo_time 未配置，日期暂未披露
State 2 — current < ipo_time 且剩余 >31 天
State 3 — current < ipo_time 且 24h < 剩余 ≤31 天
State 4 — current < ipo_time 且剩余 <24h（倒计时精度升级为 HH:MM:SS）
State 5 — ipo_time < current < market_open（IPO 已发生，开市前约 12h–2 天）
Reduce-Only。高亮卡 = Pre-Listing，下卡显示 Market Opening 倒计时。
State 6 — current > market_open 且 symbol_type = PRE_LAUNCH
Reduce-Only。高亮移至 Market Merging Phase，上卡显示 Market Opening 历史日期。
DL / SPAC · 5 种触发条件（Type 2）
State 1 — market_open 未配置（Investor Day / Proxy Statement 尚未发布）
State 2 — current < market_open 且剩余 >31 天
State 3 — current < market_open 且 24h < 剩余 ≤31 天
State 4 — current < market_open 且剩余 <24h（HH:MM:SS）
State 5 — current > market_open 且 symbol_type = PRE_LAUNCH
Reduce-Only。Market Merging Phase。无 Pre-Listing 中间态。
Type 1 vs Type 2 文案差异
State IPO · Type 1（6 States） DL / SPAC · Type 2（5 States）
1 Pre-IPO · To Be Disclosed Pre-Public · To Be Disclosed
2–4 Pre-IPO · Est. IPO Date 倒计时 Pre-Public · Market Opening 倒计时
5 Pre-Listing · Est. IPO Date 倒计时 Market Merging Phase（无 Pre-Listing 中间态）
6 Market Merging Phase —（DL/SPAC 无此 State）
由后端 listing_type 决定：IPO → type1；DL / SPAC → type2。IPO 跟踪 ipo_time + market_open；DL/SPAC 只跟踪 market_open。
高亮卡 = 当前阶段
白框 + 深背景 = 用户现在所在阶段。非高亮 = 下一阶段预告。
脚注 * · 只减仓提醒
IPO · Type 1
During the weekend/holiday/IPO phase, some symbols may be under position risk control; only reduce-only orders are allowed.
DL / SPAC · Type 2
During the weekend/holiday/Pre-Public phase, some symbols may be under position risk control; only reduce-only orders are allowed.
（Pre-Public 指 market_open 前的整个待开市区间）
数据来源 ipo_time 数据来源 & 日期变更处理（IPO / 直接上市） ipo_time 字段决定弹窗状态流转的核心时间节点；SPAC 需等股东投票通过后才能确定
时间节点 来源 确定程度 能否使用
路演开始
IPO 前 1～2 周		 Bloomberg / Reuters / CNBC 路演报道；承销商路演材料 软确认 ~90% ✓ 可以填入
覆盖 State 2 / State 3 倒计时展示
424B4 提交
IPO 前一晚		 SEC EDGAR 最终招股书；精确日期 + 发行价同时披露 硬确认 100% △ 最准但太晚
此时距 IPO 不足 24h，进入 State 1
推荐做法：路演开始时填入软确认日期，覆盖 State 2/3 倒计时展示。等 424B4 确认后若日期有出入，再按下方变更流程更新。
⚠ 约 10% 概率：路演日期 ≠ 最终 IPO 日期（推迟或提前）
公司可能因市场情况、监管审查或承销商建议，在路演后调整 IPO 日期。此时需要手动更新 ipo_time，前端状态将自动重算。
1
监听 SEC EDGAR 的 S-1/A 修订或 NASDAQ/NYSE 公告，发现日期变动后第一时间更新后台 ipo_time 字段。
2
前端倒计时基于 ipo_time 实时计算，更新字段后弹窗状态自动跳转——若新日期更远则从 State 1 退回 State 3/2，若更近则加速进入 State 1。
3
日期变更属于高风险操作，建议同步在平台公告用户，避免因倒计时突变引发误操作。

Pre-IPO 阶段（listing_type = IPO）
SPCX-PERP 行子标题显示橙色 Pre-IPO 标签，位于美股（Stocks Tab）列表中，选标的前即感知该合约处于特殊 IPO 阶段。
Pre-Public 阶段（listing_type = DL / SPAC）
SPCX-PERP 行子标题显示橙色 Pre-Public 标签。Pre-Public 用于与传统 IPO 区分，避免用户误以为是 IPO 路径。
⚠ 边界情况：若 Pre-IPO 合约终止上市但指数源仍有流动性，进入 Pre-Public 中间态（待重新确认上市路径）。
country_stock — 标签消失 开发手动
Market Merging 结束后，开发手动将合约类型切为 country_stock（如 US_STOCK）。Pre-IPO / Pre-Public 标签消失，SPCX-PERP 变为普通美股合约行，与 TSLA-PERP 等无差别展示。

IPO 路径 · 4 阶段
① Pre-IPO（橙色）— State 1，ipo_time 未配置
② Pre-Listing（橙色）— States 2–4 + State 5 前期，距开市 > 24h
③ Listing HH:MM:SS（橙色倒计时）— State 5 最后 24h，距 market_open ≤ 24h
④ Market Merging（红色）— State 6，集中竞价 开发手动
DL / SPAC 路径 · 3 阶段
① Pre-Public（橙色）— States 1–3，market_open 未配置或距开盘 > 24h
② Public HH:MM:SS（橙色倒计时）— State 4，距 market_open ≤ 24h
③ Market Merging（红色）— State 5，首次开盘波动剧烈 开发手动
country_stock — 标签消失 开发手动
价格稳定后开发手动将 symbol 切为 country_stock（如 US_STOCK），所有标签消失，前端按普通 TradFi Perp 规则展示。
